# Лабораторная работа №7 — Лента постов

Лента постов с бесконечным скроллом, поиском, вкладками по авторам, 
лайками, скелетонами и модальным окном. Данные получаются с 
`jsonplaceholder.typicode.com` через `fetch` и `async/await`.

## Автор

**ФИО:** Лапунова Арина Сергеевна  
**Группа:** 11

## Содержимое папки

- `index.html` — разметка
- `style.css` — розовая тема с сердечками и скелетонами
- `script.js` — логика загрузки, фильтрации, лайков, модального окна

## Функционал

- Загрузка постов партиями по 10 штук
- **Вкладки по авторам:** «Все», «Автор 1»–«Автор 5»
- **Бесконечный скролл** с автоподгрузкой
- **Поиск** по заголовку с дебаунсом (300 мс)
- **Скелетоны** во время загрузки (вместо спиннера)
- **Разные цвета** у карточек по авторам (полоска слева + рамка)
- **Аватарка автора** через `i.pravatar.cc`
- **Лайки:** кликабельные, с сохранением в `localStorage`
- **Клик на карточку** — открывает модальное окно с полным текстом
- **Кнопка «Наверх»** — появляется при скролле, плавно возвращает
- **Обработка ошибок** и индикатор окончания списка

## Технические особенности

- Запросы через `fetch` с `async/await` в `try/catch`
- Пагинация через `?_start=...&_limit=...`
- Данные в общем массиве `allPosts`, фильтрация на клиенте
- Дебаунс через `setTimeout`/`clearTimeout`
- Лайки в `localStorage` по ключу `task7-likes`
- Модалка с `Escape` и кликом по оверлею
