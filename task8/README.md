# Zen-Money — учёт личных финансов

Простое приложение для учёта доходов и расходов. Работает с локальным сервером `json-server`, данные хранятся в файле `db.json`.

## Требования

- [Node.js](https://nodejs.org/) (версия 16 или выше)
- Установленный пакет `json-server`
- Любой современный браузер (Chrome, Firefox, Edge)

## Установка json-server

Если `json-server` ещё не установлен на компьютере, выполните один раз в терминале:

```bash
npm install -g json-server
