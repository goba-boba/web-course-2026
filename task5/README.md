# Лабораторная работа №5 — Игра «Simon говорит»

Игра «Симон говорит» на чистом JavaScript. Дизайн — неоновый космос: 
тёмный фон, круглые светящиеся сектора с силуэтами котиков, анимация пульсации.

## Автор

**ФИО:** Лапунова Арина Сергеевна  
**Группа:** 11

## Содержимое папки

- `index.html` — разметка (игровое поле, SVG-котики, кнопка «Старт»)
- `style.css` — неоновый дизайн, анимации подсветки
- `script.js` — логика игры

## Правила

Компьютер по очереди подсвечивает 4 цветных сектора (котиков). 
Игрок должен повторить эту последовательность, нажимая на сектора в том же порядке.
- Каждый успешный раунд добавляет **один** новый шаг в конец последовательности.
- Если игрок ошибается — игра заканчивается, показывается достигнутый уровень.

## Функционал

- Генерация случайной последовательности (0–3)
- Воспроизведение последовательности с задержками (подсветка секторов)
- Блокировка кликов во время показа последовательности компьютером
- Ввод игрока: клики по секторам
- Увеличение уровня после успешного раунда
- Окончание игры при ошибке с отображением достигнутого уровня
- Кнопка «Старт» / «Заново» для сброса игры

## Технические особенности

- Асинхронный показ последовательности через `async/await` и `sleep` (обёртка над `setTimeout`).
- Состояние игры хранится в переменных: `sequence`, `userSequence`, `level`, `isPlaying`, `isGameOver`.
- Обработчики через `addEventListener` (делегирование кликов на родительский `board`).
- Дизайн: неоновое свечение, пульсация фона, SVG-силуэты котиков разных цветов.
- Блокировка кнопок через CSS-класс `.disabled` и флаг `isPlaying`.
