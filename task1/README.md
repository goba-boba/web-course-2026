# Лабораторная работа №1 — Резюме

Одностраничное резюме, свёрстанное с использованием семантических тегов HTML5 
и Flexbox. Стиль — Cozy Cottagecore: тёплые кремовые и терракотовые оттенки, 
рукописные шрифты, уютная атмосфера.

## Автор

**ФИО:** Лапунова Арина Сергеевна  
**Группа:** 11

## Содержимое папки

- `index.html` — разметка страницы
- `style.css` — стили
- `avatar.jpg` — фотография для шапки резюме

## Структура страницы

| Блок | Тег | Что внутри |
|---|---|---|
| Шапка | `<header>` | Фото, имя, специальность, слоган |
| Навигация | `<nav>` | Якорные ссылки на разделы |
| О себе | `<section>` | Краткая биография |
| Образование | `<section>` | Список мест учёбы |
| Навыки | `<section>` | 100 языков программирования + английский |
| Контакты | `<footer>` | Email, Telegram, телефон |

## Технические особенности

- **Семантическая вёрстка:** используются `header`, `nav`, `main`, `section`, `footer`.
- **Flexbox** для раскладки: шапка, навигация, блоки навыков, контакты.
- **Внешний CSS:** все стили вынесены в `style.css`, инлайн-стилей нет.
- **Шрифты:** Caveat (рукописный) для заголовков, Nunito для основного текста.
- **Ховер-эффекты:** плавные переходы цвета и лёгкий наклон элементов при наведении.
