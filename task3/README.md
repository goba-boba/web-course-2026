# Лабораторная работа №3 — Todo-list

Интерактивный список задач на чистом JavaScript. Дизайн — страница школьной 
тетради в клетку: рукописные шрифты, синие чернила, красные пометки.

## Автор

**ФИО:** Лапунова Арина Сергеевна  
**Группа:** 11

## Содержимое папки

- `index.html` — разметка
- `style.css` — стили (Notebook: тетрадь в клетку)
- `script.js` — вся логика приложения

## Функционал

- Добавление задачи кнопкой «✎» или клавишей Enter
- Проверка на пустую строку
- Чекбокс «выполнено» — задача зачёркивается красной линией
- Кнопка удаления «✗» (появляется при наведении)
- Счётчик: «Осталось: N · Выполнено: M»
- Фильтры: «Все», «Активные», «Выполнено»
- Список хранится в массиве объектов `{ id, text, completed }`
- Дата в шапке обновляется автоматически

## Технические особенности

- Фон-«клетка» нарисован через CSS-градиенты (без картинок).
- Красная линия на полях — псевдоэлемент `::before`.
- Состояние (массив `tasks`) отделено от интерфейса — рендер из данных.
- Обработчики событий через `addEventListener`.
- Методы массивов: `filter`, `find`, `map`.
