# Лабораторная работа №2 — Адаптивный лендинг

Одностраничный лендинг студии маникюра, свёрстанный по принципу Mobile First 
с использованием CSS Grid для крупной сетки и Flexbox для внутренних блоков.

## Автор

**ФИО:** Лапунова Арина Сергеевна  
**Группа:** 11

## Содержимое папки

- `index.html` — разметка страницы
- `style.css` — стили
- `script.js` — обработка отправки формы
- `img/` — изображения для секций

## Структура страницы

| Блок | Что внутри |
|---|---|
| Шапка | Логотип, гамбургер-меню, навигация |
| Hero | Заголовок, описание, кнопка «Записаться» |
| О нас | Фото мастера + текст о студии |
| Услуги | 3 карточки: маникюр, педикюр, дизайн |
| Галерея | 4 фотографии работ |
| Форма | Имя, телефон, комментарий, кнопка «Отправить» |
| Подвал | Копирайт |

## Контрольные точки адаптива

- **Мобильный:** до 767px — одна колонка, гамбургер-меню, компактные карточки
- **Планшет:** 768px–1199px — 2 колонки услуг, 3 колонки галереи, горизонтальное меню
- **Десктоп:** от 1200px — 3 колонки услуг, 4 колонки галереи, увеличенные отступы

## Технические особенности

- **Mobile First:** базовые стили для мобильного, расширения через `@media (min-width: ...)`.
- **CSS Grid:** для сетки услуг и галереи (`grid-template-columns`).
- **Flexbox:** для шапки, карточек, формы, раскладки блоков внутри компонентов.
- **Гамбургер-меню:** работает без JavaScript, через скрытый чекбокс и `:checked`.
- **Форма:** валидация полей + сообщение об успешной отправке (в `script.js`).
- **Анимации:** плавные переходы цвета и трансформации на кнопках, карточках, ссылках.
- **Touch-friendly:** кнопки и поля минимум 44×44px.
- **Без горизонтальной прокрутки:** проверено через DevTools (`Ctrl+Shift+M`).
