# Лабораторная работа №10 — Todo-list на React

Todo-list на React с разбиением на компоненты. Состояние хранится в `App` 
через `useState` и передаётся дочерним компонентам через `props`.

**Автор:** Лапунова Арина Сергеевна, группа 11

## Запуск

Открой CMD в папке `task10` и выполни:

cd /d D:\web-course-2026\task10
npm install (в первый раз)
npm run dev

Открой в браузере адрес из терминала (обычно http://localhost:5173)

## Структура

- `src/App.jsx` — главный компонент, хранит состояние
- `src/components/TodoForm.jsx` — поле ввода + кнопка
- `src/components/TodoList.jsx` — список задач
- `src/components/TodoItem.jsx` — одна задача
- `src/components/Filters.jsx` — кнопки фильтра
- `src/components/Stats.jsx` — счётчики
- `src/App.css` — стили

## Возможности

- Добавление задач через форму (Enter или кнопка)
- Отметка «выполнено» через чекбокс
- Удаление задач
- Фильтры: «Все», «Активные», «Завершённые»
- Счётчики: всего, осталось, выполнено
- Уникальный `key={task.id}` (не индекс массива)

## Компоненты

- Все функциональные, без классов
- Используются хуки `useState`
- Данные передаются через `props` с JSDoc-типизацией
- `TodoItem` не хранит своё состояние — только принимает `task` и вызывает `onToggle` / `onDelete`
