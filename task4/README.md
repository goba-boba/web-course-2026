# Лабораторная работа №4 — Быки и коровы

Игра «Быки и коровы» на чистом JavaScript. Дизайн — деревенский: 
клетчатая скатерть, пшеничные тона, тёплое дерево, рукописные шрифты.

**ФИО:** Лапунова Арина Сергеевна

## Содержимое папки

- `index.html` — разметка
- `style.css` — деревенский дизайн
- `script.js` — логика игры

## Правила

Компьютер загадывает 4 неповторяющиеся цифры (0–9). Игрок вводит свою догадку — тоже 4 цифры.
- 🐂 **Бык** — цифра угадана и стоит на своём месте.
- 🐄 **Корова** — цифра есть в загаданном числе, но на другом месте.

## Функционал

- Генерация случайного числа без повторяющихся цифр
- Поле ввода и кнопка «Проверить»
- Валидация: ровно 4 цифры, все разные, только цифры
- История попыток: «1234 → 1 бык · 2 коровы»
- Счётчик попыток
- Победа при 4 быках — блокировка полей и сообщение
- Кнопка «Новая игра» — сброс состояния

## Технические особенности

- Отдельные функции: `generateSecretNumber`, `validateInput`, `countBullsAndCows`.
- История хранится в массиве объектов, рендер из данных.
- Обработчики через `addEventListener` (без `onclick` в HTML).
- Дизайн: фон-«скатерть» через CSS-градиенты, кнопки с эффектом «нажатия», 🌾🌻🐄🐂 в интерфейсе.
