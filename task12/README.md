# Лабораторные работы №12–13 — Zen-Money на Next.js

Перенос проекта Zen-Money с чистого JS на Next.js. Освоение файлового роутинга 
и разницы между CSR/SSR/SSG.

**Автор:** Лапунова Арина Сергеевна, группа 11

## Запуск

Открой **два окна CMD** и выполни по очереди:

**Окно 1 — сервер данных (не закрывать):**

cd /d D:\web-course-2026\task12
json-server --watch db.json --port 3001

**Окно 2 — Next.js (не закрывать):**

cd /d D:\web-course-2026\task12
npm run dev

Открой в браузере: http://localhost:3000

## Структура

- `app/layout.js` — общий layout с навигацией
- `app/page.js` — главная, список операций
- `app/add/page.js` — форма добавления
- `app/stats/page.js` — сводка по доходам и расходам
- `app/globals.css` — стили
- `lib/api.js` — работа с json-server через fetch
- `db.json` — данные

## Страницы (файловый роутинг)

- `/` → `app/page.js` — список всех операций
- `/add` → `app/add/page.js` — добавление операции
- `/stats` → `app/stats/page.js` — доходы, расходы, баланс

## Возможности

- Просмотр списка операций
- Добавление операции (сумма, тип, категория, дата, комментарий)
- Удаление операции
- Сводка: доходы, расходы, баланс
- Навигация между страницами через `next/link` (без перезагрузки)

## Технические особенности

- Файловый роутинг App Router (папки = пути)
- Клиентские компоненты через `'use client'`
- Все запросы через `fetch` с `async/await` внутри `useEffect`
- Навигация через `<Link href="...">` вместо `<a href="...">`
