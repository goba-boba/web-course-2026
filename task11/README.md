# Лабораторная работа №11 — Todo-list на React (сортировка + useEffect)

Продолжение лабораторной №10. Добавлены сортировка задач и `useEffect` 
для сохранения в localStorage.

**Автор:** Лапунова Арина Сергеевна, группа 11

## Запуск

Открой CMD в папке `task11` и выполни:

cd /d D:\web-course-2026\task11
npm install
npm run dev

Открой в браузере адрес из терминала (обычно http://localhost:5173)

## Структура

- `src/App.jsx` — главный компонент, хранит состояние
- `src/components/TodoForm.jsx` — поле ввода + кнопка
- `src/components/TodoList.jsx` — список задач
- `src/components/TodoItem.jsx` — одна задача
- `src/components/Filters.jsx` — кнопки фильтра
- `src/components/SortSelect.jsx` — выпадающий список сортировки
- `src/components/Stats.jsx` — счётчики
- `src/App.css` — стили

## Возможности

- Добавление, отметка «выполнено» и удаление задач
- Фильтры: «Все», «Активные», «Завершённые»
- Сортировка: по алфавиту (А→Я, Я→А), по дате добавления (новые/старые)
- Счётчики: всего, осталось, выполнено
- Сохранение задач в localStorage через useEffect (загружаются при перезагрузке)

## Технические особенности

- Все компоненты функциональные, на хуках
- Используется useState + useEffect
- Массив не мутируется при сортировке — `[...tasks].sort(...)`
- Уникальный `key={task.id}`
