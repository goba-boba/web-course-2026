# Zen-Money — учёт финансов (занятие 9)

## Как запустить

1. Установить json-server (если ещё не установлен):
npm install -g json-server

2. Открыть терминал в папке `task9`.

3. Запустить сервер:
json-server --watch db.json --port 3001

4. Открыть `index.html` **через Live Server в VS Code** (не двойным кликом — ES-модули не работают через `file://`).

## Возможности

- CRUD операций (доход / расход)
- Фильтры: по типу, категории, диапазону дат
- Создание своих категорий
- Светлая / тёмная тема
- Сохранение настроек (тема и фильтры) в localStorage
- Итоговая сводка: доходы, расходы, баланс

## Важно

- Проект **не работает** без json-server.
- Файлы должны открываться через HTTP (Live Server), иначе ES-модули не загрузятся.
- Транзакции хранятся на сервере в `db.json`, а не в localStorage.
