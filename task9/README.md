# Zen-Money — учёт финансов (с фильтрами и темой)

Приложение для учёта доходов и расходов на чистом JS с сервером `json-server`. 
Дополнено фильтрами, тёмной темой и созданием своих категорий.

**Автор:** Лапунова Арина Сергеевна, группа 11

## Запуск

Открой **два окна CMD** и выполни по очереди:

**Окно 1 — сервер данных (не закрывать):**

cd /d D:\web-course-2026\task9
json-server --watch db.json --port 3001


**Окно 2 — веб-сервер (не закрывать):**

cd /d D:\web-course-2026\task9
npx serve -l 5500


Затем открой в браузере: **http://localhost:5500**

## Требования

- Node.js
- `json-server` (`npm install -g json-server`)

## Возможности

- Добавление, редактирование и удаление операций (доход / расход)
- Итоговая сводка: доходы, расходы, баланс
- Фильтры: по типу, категории и диапазону дат
- Своя тема: переключение светлой / тёмной (сохраняется в localStorage)
- Создание своих категорий через форму
- Валидация формы
- Настройки (тема + фильтры) сохраняются в localStorage

## Структура

- `index.html` — разметка
- `style.css` — стили (светлая и тёмная темы)
- `api.js` — работа с сервером
- `ui.js` — отрисовка и фильтрация
- `main.js` — события, состояние, localStorage
- `db.json` — данные

## Важно

- Не открывай `index.html` двойным кликом — ES-модули не загрузятся. Только через `http://localhost:5500`.
- Не запускай `task8` и `task9` одновременно — у них одинаковые порты.
