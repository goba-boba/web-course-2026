# Лабораторная работа №6 — Игра на Canvas («Змейка»)

Игра «Змейка», написанная на чистом JavaScript с использованием HTML5 Canvas. 
Код разбит на ES-модули для разделения логики и отрисовки. Вместо классического 
яблока змейка собирает пульсирующие неоновые сердечки.

## Запуск

Так как проект использует ES-модули (`import`/`export`), открывать `index.html` двойным кликом нельзя — браузер заблокирует загрузку скриптов. Нужно использовать локальный сервер.

**Способ 1: Через расширение Live Server в VS Code**
Откройте папку `task6` в VS Code, нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**.

**Способ 2: Через терминал (npx serve)**
Откройте CMD и выполните команды:
    cd /d D:\web-course-2026\task6
    npx serve -l 5500
Затем откройте в браузере: http://localhost:5500

## Содержимое папки

- `index.html` — разметка (холст, панель счёта, кнопка рестарта)
- `style.css` — стили игры
- `js/config.js` — константы игры (размер сетки, скорость)
- `js/logic.js` — чистая логика (движение, коллизии, спавн яблок)
- `js/render.js` — отрисовка графики на Canvas
- `js/script.js` — точка входа, игровой цикл и обработка клавиатуры

## Управление

- **Стрелки** (Вверх, Вниз, Влево, Вправо) — поворот змейки.
- Разворот на 180° запрещён (если змейка ползёт вправо, нажатие «влево» игнорируется).

## Функционал

- Движение змейки по сетке 20×20.
- Появление сердечка (яблока) в случайной свободной клетке.
- Увеличение змейки на 1 сегмент при съедании сердечка.
- Увеличение счёта на 10 очков за каждое сердечко.
- Окончание игры при столкновении со стеной или собственным хвостом.
- Отображение итогового счёта и кнопка «Начать заново».
- Рестарт без перезагрузки страницы.

## Технические особенности

- **Игровой цикл:** реализован через `requestAnimationFrame` (без `setInterval`).
- **Скорость:** движение змейки происходит с постоянной скоростью независимо от FPS монитора. Используется расчёт `deltaTime` (разница между текущим временем и временем прошлого шага).
- **Разделение логики и отрисовки:** 
  - `logic.js` обновляет состояние (функция `update`), не зная о Canvas.
  - `render.js` отрисовывает текущее состояние (функция `draw`), не меняя его.
- **Отрисовка сердечка:** выполнена математически через кривые Безье (`ctx.bezierCurveTo`), без использования готовых картинок.
- **Модульность:** код разбит на именованные функции и файлы.
